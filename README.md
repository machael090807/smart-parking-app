# Smart Parking APP

智慧路邊停車媒合 APP

## Version

v1.0.3

## Architecture

- `generate.py`: downloads New Taipei City roadside parking data and generates `docs/parking.json`
- `docs/index.html`: static mobile/desktop web app
- GitHub Actions: refreshes parking data and deploys GitHub Pages automatically

## GitHub Pages

Set:

`Settings -> Pages -> Source -> GitHub Actions`
